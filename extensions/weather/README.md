# 天气 · 早安

Aurabot 用户扩展。主人说「早」的时候，她顺口报一句今天要不要带伞、穿几件；主人一直没开口，早上也会主动来问候一次。天气按城市查，数据来自 [Open-Meteo](https://open-meteo.com/)（免费、不用 key）。

```
你：早
她：教主早安。今天合肥小雨，15 度上下，出门记得带伞，穿件长袖加薄外套刚好。
```

## 她怎么知道天气

- 主人私聊里，每轮对话都会带一条【你手机上的天气】：现在多少度、体感多少、今天/明天的温度区间和降雨概率，再加一句出门建议。
- 你说「早」「早安」「早上好」「早呀」「早啊」「早哇」「早早」「morning」「gm」，或者句子里带「早安」「早上好」时，那一轮会额外提醒她一句：顺口说带不带伞、穿几件。
- 「早点睡」这种不会被当成早安。

天气是按**城市**查的；面板里另有一个「区 / 街道」，只影响她怎么称呼你那儿（比如「合肥 · 蜀山区」），不改变预报精度。

## 你不说，她也会来

- 默认早上 7:00~8:30 之间，每天随机挑一分钟（同一天重启也不会变），你还没开口就主动发一条早安，带天气。
- 周末自动晚 1.5 小时（可关）。
- 你 5 点以后已经说过话，就不补这条（可关）——你先说了「早」，她正常回就行。
- 主动问候走的是你们真实的私聊会话：人格、记忆、语气都在，不是模板；一天只发一次。
- 已经主动问候过的话，上下文里会注明「今天已经说过」，你再说「早」时她不会重复一遍早安。

## 面板设置

面板里会多一个「天气 · 早安」页（在「日志」前面），设置项：

| 设置 | 默认 | 说明 |
|---|---|---|
| 城市 | 合肥 | 天气按这个城市查 |
| 区 / 街道 | 蜀山区 | 只用于显示，留空就只显示城市 |
| 带伞提醒阈值 | 40% | 降雨概率到这个数就提醒带伞 |
| 我没说话时也主动问候 | 开 | 关掉就只在你说话时回应 |
| 最早 / 最晚几点 | 07:00 / 08:30 | 在这之间随机挑一分钟 |
| 周末晚一点 | 开 | 周六周日 +1.5 小时 |
| 你已经说过话就不打扰 | 开 | 5 点后你发过消息就不补问候 |

页面下方还有「查一下现在的天气」，只预览、不发 QQ。

## 安装

```powershell
cd extensions\weather
npm run install:module
```

会把 `index.mjs`、`panel.js`、`README.md`、`package.json` 复制到
`%USERPROFILE%\.dsh\plugins-data\aurabot\modules\weather\`，Aurabot 几秒内自动加载，不用重启。

也可以指定目录：

```powershell
node scripts/install.mjs D:\somewhere\modules\weather
```

## 测试

```powershell
cd extensions\weather
npm test
```

测试不联网：`fetch` 被替换成固定数据，覆盖天气解析、主人/群聊上下文、带伞阈值、早安触发词、主动问候只发一次。

## 几个实现上的取舍

- **为什么把天气放进系统上下文，而不是让她每次调工具**：小模型（比如 flash + low）经常懒得调工具，等一轮工具调用还会慢一两秒。天气缓存 30 分钟，直接放进上下文，她张嘴就知道。
- **为什么主动问候用 `pushToSession`**：走真实会话，她记得自己说过什么；用 `api.send` 发模板会像机器人，也不会进会话历史。
- **穿衣为什么是固定表**：体感温度 → 件数，避免模型今天说两件、明天说三件。模型只负责措辞。
- **傍晚以后按「明天」说**：晚上 6 点后再拿今天的温度建议穿衣就不对了。
- **群里不注入天气**：群聊是 `social` 档，别人看不到主人在哪个城市；群里有人问天气，她会先问城市，再调 `weather_now`。
- **接口失败不打扰**：超时 6 秒，失败保留上一次缓存、5 分钟内不重试；主动问候照样发，只是不提天气。
