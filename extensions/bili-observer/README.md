# B站观察者

Aurabot 用户扩展。别人发来 B 站链接时她能**看**这个视频（标题、简介、字幕、热评、弹幕）；她也会定时自己去刷推荐流，把「值得看」的私聊分享给主人；还能订阅 UP 主动态，官方号一发公告就告诉主人。

账号只读：不评论、不发弹幕、不改资料。唯一的写入是**点赞**和**收藏**（都可以关）。

这个扩展是从内置模块 `bili` 拆出来的：配置仍然读写插件里的 `cfg.bili`，面板走扩展自己的 `/config` 路由，所以数据、订阅、截图、日报都跟以前共用同一份。

## 她能做什么

| 你做什么 | 她做什么 |
|---|---|
| 发一条 B 站链接 / BV 号 | 用 `bili_watch` 读标题、简介、字幕、热评、弹幕，然后跟你聊 |
| 想看她刷到了什么 | `qq_list_shots` 列截图，`qq_send_shot` 挑一张发出来 |
| 「订阅一下这个 UP」 | `bili_subscribe`（只有主人能改） |
| 「现在订了谁」 | `bili_subs` |
| 什么都不做 | 按 `intervalHours` 自己去刷，值得看的私聊发你，21 点推一条日报摘要 |

刷视频的会话固定叫 `system:bili`，可以单独指定模型（面板「刷视频用什么模型」），跟聊天模型分开。

## 订阅 UP 主动态

订阅列表存在 `cfg.bili.subs` 里，每个号可以有：

- `filters`：过滤掉不想看的类型（`forward` 转发 / `lottery` 抽奖 / `video` 视频 / `article` 专栏 / `draw` 图文 / `live` 直播 / `live_end` 下播），别的词当正则过滤正文
- `prompt`：这个号特别在意什么
- `mode` / `minLevel`：AI 过滤开关和推送门槛
- `examples`：判定例子（「这种要推 / 这种别推」，最多 5 条）

AI 过滤默认关。关着就是原样转发，不花 token；开着会先让模型判断要不要推、压成一句话 + 要点，一轮多条还能合成一条 digest（最多 3 张图）。

## 截图库

开着「抽帧看画面」（需要 ffmpeg + 能看图的模型）时，刷完会按 `shotChance` 概率截一帧存到本机，最多留 `shotLibrary` 张。面板里能看全部、能手动删，聊天里也能让她发一张。

## 安装

```sh
npm run install:module
```

默认装到 `~/.dsh/plugins-data/aurabot/modules/bili-observer`，遵守 `DSH_HOME`、`AURABOT_DATA_DIR`；也可以指定目标：

```sh
npm run install:module -- "D:/my-data/aurabot/modules/bili-observer"
```

没有依赖、不用构建（`bili/` 子目录里是随扩展一起复制的实现，不用单独装）。装好后 Aurabot 几秒内自动热重载，面板「平台」组里能看到「B站观察者」。

装好扩展后内置的 `bili` 模块不再启用，避免两边同时刷同一个账号。

## 设置

面板「扩展 → B站观察者」，配置写回 `cfg.bili`：

| 项 | 默认 | 说明 |
|---|---|---|
| 启用 | 关 | 总开关 |
| 只要订阅 | 关 | 开着就不刷视频、不点赞不收藏、不发截图，只查订阅的 UP 主动态 |
| SESSDATA / bili_jct | 空 | 登录凭证。两个都不填也能看视频，只是不能点赞收藏 |
| 定时自己去刷 | 开 | |
| 多久刷一轮 | 4 小时 | |
| 每天最多刷 | 3 轮 | |
| 一轮看几个视频 | 3 | |
| 播放量门槛 | 5000 | 只对搜索 / 热门生效，推荐流不过滤 |
| 只看最近 | 60 天 | 同上，`0` = 不限 |
| 私聊分享给主人 | 开 | |
| 顺手点赞 | 开 | 只给「值得看」，受日上限管 |
| 每天最多点赞 / 收藏 | 5 / 10 | |
| 每天推一条日报摘要 | 开 | 几点推（0-23） |
| 抽帧看画面 | 关 | 需要 ffmpeg + 视觉模型 |
| 每个视频看几帧 | 6 | |
| 刷完顺手发截图 | 35% | `0` = 不发 |
| 截图库张数 | 300 | 超了自动删最旧的 |
| 刷视频用什么模型 | 跟随聊天 | 留空 = 跟随默认模型 |
| 订阅查询间隔 | 15 分钟 | B 站对高频读会降级，别调太小 |
| 号与号之间歇几秒 | 6 | 同一个出口连读容易被 -352 |
| 一个号一次最多推几条 | 3 | 防止隔几天没开就刷屏 |
| 图文动态把配图发过去 | 开 | |
| 一轮多条合成一条 | 开 | AI 过滤开着时才生效 |
| AI 过滤 | 关 | |
| 判定用模型 | 跟随默认 | |
| 推送门槛 | 值得说一声 | 1 都推 / 2 值得说一声 / 3 很重要 |

## 已知边界

- **只有主人能改订阅**：`bili_subscribe` / `bili_unsubscribe` 会检查这一轮里有没有主人
- **截图只给主人看**：`qq_send_shot` / `qq_list_shots` 会检查这一轮的发送者是不是全是主人
- **观察者模式没有公开动作**：评论、弹幕、改资料的工具和接口都已经删掉，`posture` 只剩 `observer` / `social` 两种名义值，写闸门只放行点赞和收藏
- **数据跟内置模块共用**：`bili.json`、`bili-seen.json`、`bili-reports/`、`bili-digest/`、`bili-subs.json`、`bili-shots/`、`bili-audio/` 都在同一个数据目录下，装扩展不用迁移
- **面板保存只写 `cfg.bili`**：保存后会刷新全局草稿，否则客户端那份旧草稿会在下次全局保存时把 B 站配置覆盖回去

## 安全

- Cookie 只在服务端用，面板回传时脱敏成结尾 4 位（`sessdataHint` / `biliJctHint`），空串 = 保留原值、`null` = 清空
- 截图和音频都落在本机数据目录，不进模型上下文
- 扩展路由挂在 `/aurabot/api/ext/bili-observer/*` 下，不过 admin token 闸，但仍有 CSRF 和 host 校验
